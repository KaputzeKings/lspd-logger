# LSPD Log Assistent

Automatisiertes Logging- und Auswertungstool für den Los Santos Police Department Dienst.

### Features
- ⚡ **1-Klick Discord Forum Logging:** Hotkeys für alle Einsatzarten (Inhaftierung, Global, Local, Event, Shoprob, FZ-Raid, Streifenpartner).
- 📊 **Echtzeit Uprank-Zähler:** Zählt Inhaftierungen, Events, Shoprobs, FZ-Raids, Streifenpartner live mit.
- 🎨 **Vollständig anpassbares HUD:** 5 Design-Presets (u.a. Schwarz-Lila), Color Picker, Skalierung & Transparenz.
- 🔄 **Integrierter Auto-Updater:** Automatische Erkennung und Installation neuer Versionen direkt über GitHub Releases.
